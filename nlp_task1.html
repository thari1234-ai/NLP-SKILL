5-Gram Search Autocomplete with Kneser-Ney Smoothing

This single-page demo trains a sparse 5-gram language model from scratch, applies discounted probabilities with recursive back-off, and predicts likely query completions for real-time search suggestions.

    What the model does

    • Sparse 5-gram counts: it stores only observed word sequences.
    • Kneser-Ney smoothing: it discounts frequent n-grams and backs off to shorter histories.
    • Recursive back-off: if a 5-gram is missing, it falls back to 4-gram, 3-gram, and so on.
    • OOV handling: unseen words are mapped to a dynamic unknown token so the system remains robust.

    Example: for the prefix “best places to visit”, the model ranks continuations such as “in india”, “near me”, “in chennai”, and “during summer”.
